# سایت شخصی آیسا حاجی‌پور + دمو‌ساز تعاملی

این پروژه در پوشه‌ای مستقل از پروژه‌های دیگر مخزن ساخته شده است. فناوری‌ها: Next.js App Router، React، TypeScript، Motion و CSS. فونت فارسی متغیر Vazirmatn استفاده می‌شود. پوستهٔ سایت اصلی و دموساز از یک هویت سرمه‌ای، بنفش و آبی پیروی می‌کند؛ دموهای کسب‌وکارها رنگ‌های مستقل خودشان را دارند. تصاویر اختصاصی کانسپت‌ها با ImageGen ساخته و به WebP بهینه شده‌اند. برای نسخهٔ فعلی، سرویس Node.js جداگانه لازم نیست؛ Next.js هم صفحات و هم مسیرهای سرور احتمالی آینده را مدیریت می‌کند.

در نسخهٔ تازه، پس‌زمینهٔ سرمه‌ای روشن‌تر شده و رنگ‌های شاخص بنفش الکتریکی، آبی پیکسلی، فیروزه‌ای، سبز و صورتی نورانی هستند. نوار کلمات با دو گروه یکسان به‌صورت پیوسته تکرار می‌شود. بخش خدمات انتخابی است و برای هر خدمت نتیجه و تحویل‌دادنی‌ها را نشان می‌دهد. کادرهای توانایی‌ها بر اساس رزومهٔ ارائه‌شده نوشته شده‌اند؛ هر کدام نمایش بصری مستقل دارند و نام فناوری‌ها با کلیک توضیح کاربردشان را باز می‌کند. ویترین صفحهٔ اصلی لینک روشن برای ورود به هر یک از شش دمو دارد. شش تصویر گرافیکی اختصاصی در `public/demos/` استفاده می‌شود و دمو ورزش تصویر عمودی جداگانه دارد؛ ایده‌ها و عبارت‌های جست‌وجوی جایگزین در `IMAGE_DIRECTIONS.md` ثبت شده‌اند. دموساز روی دسکتاپ دو کادر تنظیمات در دو سوی پیش‌نمایش دارد و در موبایل، پیش‌نمایش پس از اطلاعات کسب‌وکار قرار می‌گیرد. انتخاب اختیاری فناوری در دموساز همراه لینک و پیام سفارش ثبت می‌شود. فرم سفارش کامل در صفحهٔ اصلی و دموساز جزئیات کسب‌وکار، هدف، امکانات، محدوده، زمان، بودجه و راه ارتباط را جمع می‌کند. شبکهٔ آزمایشگاه پیکسل ۲۰×۲۰ است و هالهٔ پیکسلی موس در کل سایت رنگ انتخابی کاربر را دنبال می‌کند؛ دکمهٔ هدر برای خاموش‌کردن آن وجود دارد و انتخاب کاربر حفظ می‌شود.

## ترتیب ساخت

1. ساخت پروژهٔ مستقل و تنظیم TypeScript و Next.js.
2. طراحی دوبارهٔ صفحهٔ اصلی فارسی و راست‌به‌چپ: هیروی پیکسلی با کانسپت «یکسل» و ادیتور پایتون، آزمایشگاه پیکسلی تعاملی، خدمات، توانایی‌ها، ویترین شش دمو، فرم خلاصهٔ پروژه، پرسش‌های رایج، فرایند، درباره من و تماس. نام «یکسل» فعلاً کانسپت بصری است و نام رسمی سایت در تنظیمات همچنان آیسا حاجی‌پور است.
3. ساخت دمو‌ساز: انتخاب ۶ حوزه با شش صفحهٔ اول مستقل، ۳ تم برای هر حوزه، نام برند، تیتر، شهر، متن بخش بعدی و دکمه، عکس انتخابی کاربر، رنگ شاخص و چیدمان تصویر؛ نمایش زندهٔ دسکتاپ و موبایل.
4. اتصال درخواست پروژه به واتساپ با متن آماده شامل انتخاب‌های کاربر؛ فرم جداگانهٔ خلاصهٔ پروژه در سایت اصلی و مسیر جایگزین ایمیل و تماس.
5. آماده‌سازی سئوی فنی: metadata، عنوان و توضیح اختصاصی، canonical، Open Graph، robots، sitemap، دادهٔ ساختاری شخص/وب‌سایت و HTML معنایی. دموهای مفهومی `noindex` هستند.
6. بررسی با `npm run typecheck` و `npm run build` و آزمایش دستی در مرورگر.

## محتوای واقعی و دمو

دموها مفهومی‌اند. بخش رزرو، پرداخت، سبد خرید، برنامهٔ تمرینی و جست‌وجوی ملک در پیش‌نمایش صرفاً نمایشی هستند و در پروژهٔ واقعی هر مشتری طبق نیاز او ساخته می‌شوند. عکس انتخابی کاربر با آدرس محلی موقت مرورگر نمایش داده می‌شود، به سرور فرستاده نمی‌شود و در لینک اشتراک ذخیره نمی‌شود. پیش‌نمایش واترمارک دارد و چاپ آن پنهان شده است؛ هیچ وب‌سایتی نمی‌تواند اسکرین‌شات سیستم‌عامل را به‌طور قطعی مسدود کند. هیچ آمار مشتری، رضایت‌نامه یا نمونه‌کار غیرواقعی در سایت قرار نگرفته است. هر شش دمو چیدمان و مسیر کاربری جداگانه دارند.

## انتشار روی GitHub Pages

این سایت در مخزن مستقل `aysahajipour/aysahajipour.github.io` منتشر می‌شود و به مخزن `mobina-coach` دست نمی‌زند. با هر push به شاخهٔ `main`، گردش‌کار `.github/workflows/deploy.yml` خروجی ایستای Next.js را می‌سازد و در `https://aysahajipour.github.io/` قرار می‌دهد. مقدار `NEXT_PUBLIC_SITE_URL` در زمان ساخت روی همین آدرس تنظیم می‌شود تا canonical، نقشهٔ سایت و داده‌های ساختاری درست باشند. اجرای محلی همچنان با `npm run dev` انجام می‌شود.

برای بررسی خروجی پیش از انتشار در PowerShell:

```powershell
$env:GITHUB_PAGES = "true"
$env:NEXT_PUBLIC_SITE_URL = "https://aysahajipour.github.io"
npm run build
Remove-Item Env:GITHUB_PAGES
Remove-Item Env:NEXT_PUBLIC_SITE_URL
```

خروجی در پوشهٔ `out` ساخته می‌شود. فرم پروژه در این نسخه متن درخواست را برای واتساپ یا ایمیل آماده می‌کند و پایگاه داده یا دریافت خودکار فرم ندارد.

## تنظیمات قبل از انتشار عمومی

- برای دامنهٔ مستقل احتمالی در آینده، `NEXT_PUBLIC_SITE_URL` گردش‌کار و تنظیمات GitHub Pages را به دامنهٔ جدید تغییر دهید.
- نام، توضیح خدمات، راه‌های تماس و لینک گیت‌هاب در `src/lib/site.ts` قابل ویرایش‌اند.
- برای سئوی واقعی، نمونه‌کارهای قابل اثبات، محتوای خدمات جداگانه و متن اختصاصی هر پروژه لازم است.
- درخواست دمو اکنون در واتساپ باز می‌شود؛ کاربر باید خودش دکمهٔ ارسال را بزند. اگر ذخیرهٔ خودکار لیدها لازم شود، باید API و سرویس ذخیره/ایمیل با رضایت کاربر اضافه شود.
